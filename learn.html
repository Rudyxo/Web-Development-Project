HTML — the skeleton of every web page

HTML (HyperText Markup Language) describes what is on a page: headings, paragraphs, links, images, buttons, forms. It doesn't decide how things look or behave — it gives content structure and meaning, so browsers, search engines and screen readers all understand it. You write HTML by wrapping content in tags, and the browser turns those tags into the page you see.


1. Anatomy of an element

<a href="https://github.com/Rudyxo">My GitHub</a>
  • <a ...> </a> opening and closing tag (the closing one has a /)
  • href an attribute — extra info about the element
  • "..." the attribute's value, always in quotes
  • My GitHub the content between the tags

3. Every page starts with this skeleton

<!DOCTYPE html>          <!-- tells the browser: this is HTML5 -->
<html lang="en">
  <head>                   <!-- info ABOUT the page (not shown) -->
    <meta charset="UTF-8">
    <title>My Page</title>
    <link rel="stylesheet" href="style.css">
  </head>
  <body>                   <!-- everything visible goes here -->
    <h1>Hello!</h1>
    <script src="script.js"></script>
  </body>
</html>

CSS — the styling layer

CSS (Cascading Style Sheets) controls how HTML looks: colours, fonts, spacing, layout, animation and responsiveness. The idea is simple — select an element, then declare how it should look. "Cascading" means that when several rules apply to the same element, the browser has clear rules for which one wins (later and more specific rules beat earlier and vaguer ones).


1. Anatomy of a rule

.card {
  background: #151521;
  border-radius: 14px;
}
  • .card the selector — which elements to style
  • background a property — what to change
  • #151521 the value — what to change it to
  • Each declaration ends with ; and the whole block sits inside { }

3. Selectors you'll use every day

Element
p { color: gray; }

Styles every <p> on the page.

Class
.card { padding: 20px; }

Styles anything with class="card". Reusable.

ID
#logo { font-size: 2rem; }

Styles the one element with id="logo". Unique.

Hover
button:hover { opacity: .8; }

Applies only while the mouse is over it.

JavaScript — the behaviour

JavaScript is a real programming language that runs inside the browser. Where HTML is structure and CSS is looks, JS is what happens: reacting to clicks, changing text, validating forms, playing sound, fetching data. It works by storing information in variables, making decisions with conditions, repeating work with loops, and bundling steps into functions.


1. The five ideas behind almost every program

Variables
let name = "Rudransh";
const year = 2026;

let can change later, const can't.

Functions
function add(a, b) {
  return a + b;
}

Reusable steps. Input in, result out.

Conditions
if (score >= 60) {
  ...
} else { ... }

Do different things in different cases.

Loops
for (let i = 1; i <= 5; i++) {
  ...
}

Repeat without copy-pasting.
